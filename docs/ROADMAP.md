# Roadmap

Version 2 replaces the old dashboard with a frosted-glass ring.

## Done

- Ring: frosted glass, Alt+Space, desktop right-click, tray, drag and pin.
- Apps and Social: Start menu, Store, Edge and Chrome web apps, desktop shortcuts, Chrome and Edge profiles; open-app dots, switch and close; drag-and-drop or Ctrl+V pinning.
- Search: apps, files (Windows index and all drives), radio, timer, places.
- Radio: country lists, worldwide search, favourites, music lights.
- Watch: 10 faces, colours, flags and landmarks, animated weather, world times.
- System: screenshot, snip, record, volume, mic, brightness, Wi-Fi, Bluetooth, shortcuts, power.
- Work timer with chime, read aloud.
- 10 themes, the Customise window, shareable setups.
- Self-test (`--selftest`).

## Next

1. Hide whole sections in Customise.
2. Notes and sticky notes.
3. Calendar with reminders and a to-do list.
4. Assistant: type or talk to a local AI model (Ollama), asks before risky actions.
5. More languages for reading aloud.
6. Radio: sleep timer, alarm, add your own stream address.
7. Aeroplane mode and location.
8. One-file installer.

## Known limits

- The radio plays MP3 and AAC streams; HLS-only stations are left out.
- Brightness works on monitors with DDC/CI switched on in the monitor's own menu.
- The glass is a blurred snapshot of what's behind the ring; it refreshes when the ring opens or moves.
